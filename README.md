# 📊 Telecom Customer Complaint Prediction using Machine Learning

## 📌 Overview

This project predicts whether a telecom customer is likely to raise a complaint using machine learning techniques.

The project follows the CRISP-DM methodology and includes:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Machine Learning Models
- Model Evaluation
- Interactive Streamlit Dashboard

---

## 🚀 Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Scikit-learn
- XGBoost
- Streamlit

## 🎯 Objective

Predict customer complaints based on:

- Customer Care Contacts
- Service Score
- Payment Mode
- Revenue
- Cashback
- Customer Segment
- Customer Behaviour

---

## 📈 Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost

---

- Explore the dataset
